# Kindlr documentation

**Kindlr** is a free programming studio that runs in your web browser. You can make games, animations and small apps. (Kindlr used to be called *Blockforge*. Old projects still open.)

You can write programs in two ways:

- **Kindlr Blocks**: you drag coloured blocks and snap them together. Good for beginners.
- **Kindlr Script**: you type the same program as text. Good when programs get bigger.

Both are **the same program**. Switch between them any time: the **Kindlr Script** tab shows your blocks as text, and **Apply to blocks →** turns text back into blocks. Both run on the same safe interpreter. Your code is never turned into JavaScript.

Our mascot is **Sparky**, the little flame that greets you in every new project. 🔥

## Words you will see

| Word | Meaning |
|---|---|
| **Sprite** | A character or object on the stage, like Sparky. |
| **Stage** | The area where your project runs (480 × 360). It has backdrops. |
| **Script** | A stack of blocks that starts with a *hat* block. |
| **Hat** | A block that starts a script when something happens (an *event*). |
| **Ignite** 🔥 | The button that starts your project. (Like a "green flag".) |
| **Variable** | A named box that holds one value, like `@score`. |
| **List** | A named row of values, like `@@names`. |
| **Clone** | A copy of a sprite made while the project runs. |
