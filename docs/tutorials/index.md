# Tutorials

| Tutorial | You learn |
|---|---|
| [Clicker game](clicker.md) | events, variables, broadcast, widgets, storage, timer |
| [Quiz](quiz.md) | lists, `ask` and `answer`, loops, if/else, the console |
| [Platformer-lite](platformer.md) | physics, gravity, keys, `on_draw` shapes |
| [To-do app](notes-app.md) | program mode: widgets, lists, custom blocks, storage |

Each tutorial shows the code in Kindlr Script. To get blocks, paste the code into the **Kindlr Script** tab of the right sprite and click **Apply to blocks →**, then look at the **Blocks** tab.
